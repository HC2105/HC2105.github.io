# Modding Tools by HC2105

A central landing page linking all client-side browser utilities by **HC2105 @ TJ x HC Studio** for OMSI 2 and vehicle sound modding.

**→ [https://hc2105.github.io/](https://hc2105.github.io/)**

## Included tools

| Tool | Description | Live App |
| ---- | ----------- | -------- |
| **OMSI O3D Optimize & SCO Tools** | Merge duplicate `.o3d` material slots, scan Alpha 1/2 channels, and generate `.sco` blocks | [Open](https://hc2105.github.io/omsi-o3d-optimize-sco-tools/) |
| **Engine Recording RPM Analyzer** | Analyze engine RPM from audio recordings, tune 31-band EQ, and export stereo WAV loops | [Open](https://hc2105.github.io/engine-recording-rpm-analyzer/) |
| **OMSI Nightmap Tool** | Draw room boxes, mask window frames, and export OMSI `night/` textures | [Open](https://hc2105.github.io/omsi-nightmap-tool/omsi_nightmap_tool.html) |

## File layout

This repo ships one static portal page (`index.html`). Open it directly or host via GitHub Pages at `HC2105.github.io`.
